# HOI4 Campaign Generator

A Hearts of Iron IV campaign randomizer that spins through:

1. Country
2. Ideology
3. Political path

The country wheel uses flag-inspired wedges and radial country names.

## GitHub Pages

This repo is designed to be hosted directly with GitHub Pages.

### Publish
1. Upload `index.html` to the repository root.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select the `main` branch and `/ (root)` folder.
5. Save.

Your site will appear at a URL similar to:
`https://YOUR-USERNAME.github.io/hoi4-campaign-generator/`

## Updating
Replace or edit `index.html`, commit the change, and GitHub Pages will republish automatically.
